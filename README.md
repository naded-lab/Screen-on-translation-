# ترجمان (Tarjaman) — مترجم عربي/إنجليزي Offline + مترجم عائم

مشروع Android كامل (Kotlin + Jetpack Compose + Material 3)، مبني من الصفر بالكامل.

## المتطلبات لفتح المشروع
- Android Studio **Ladybug (2024.2)** أو أحدث
- JDK 17 (يأتي مدمجاً مع Android Studio الحديث)
- Android SDK: compileSdk/targetSdk **34**

## خطوات التشغيل الأولى (مهم جداً)
1. افتح مجلد `tarjaman` كاملاً من Android Studio: `File > Open`.
2. **الشرح**: هذا المشروع لا يحتوي على ملف `gradlew`/`gradle-wrapper.jar` الثنائي (لأن بيئة البناء التي أنشأت بها المشروع لا تملك اتصال إنترنت لتنزيله). عند فتح المشروع، Android Studio سيلاحظ ذلك تلقائياً ويعرض عليك رسالة مثل:
   > "Gradle wrapper is missing. Would you like to generate it?"

   اضغط **Yes/Generate**، أو نفّذ يدوياً من Terminal داخل Android Studio:
   ```
   gradle wrapper --gradle-version 8.7
   ```
3. بعد ذلك اضغط **Sync Project with Gradle Files** (أيقونة الفيل 🐘 أو من قائمة File).
4. أول مزامنة ستُنزّل كل المكتبات (ML Kit، Compose، إلخ) — تحتاج إنترنت في هذه الخطوة فقط.
5. لبناء APK: `Build > Build App Bundle(s)/APK(s) > Build APK(s)`
   لبناء AAB (للنشر على المتجر): `Build > Build App Bundle(s)/APK(s) > Build Bundle(s)`

## الميزات المُنجزة

### 1. الترجمة الأساسية (Offline بالكامل)
- محرك **ML Kit Translate** من Google، يعمل على الجهاز 100% بعد تنزيل نموذج اللغة مرة واحدة (~30MB).
- شاشة "ترجمة": حقل نص، تبديل فوري بين عربي/إنجليزي، نسخ، مشاركة.
- شريحة توضح حالة كل نموذج لغة بوضوح: **جاهز / يُنزَّل الآن / يحتاج تنزيل**.

### 2. المترجم العائم (لقراءة المانهوا فوق تطبيقات مثل Mihon)
- زر عائم صغير قابل للسحب فوق أي تطبيق آخر.
- عند الضغط عليه: يلتقط لقطة واحدة فقط من الشاشة (وليس بثاً مستمراً — توفير بطارية)، عبر `MediaProjection` الرسمي من أندرويد.
- يقرأ النص بتقنية OCR محلية (ML Kit Text Recognition، نص لاتيني/إنجليزي).
- يترجم كل فقاعة **إنجليزي ← عربي** (ثابت، حسب طلبك) ويرسم الترجمة فوق مكان الفقاعة الأصلية.
- **لا يحفظ أي صورة على القرص ولا يرسلها لأي خادم** — كل المعالجة في ذاكرة التطبيق المؤقتة فقط.
- زر إيقاف مباشر من الإشعار (Notification) دون الحاجة لفتح التطبيق.

**أذونات ستحتاج الموافقة عليها يدوياً عند أول تشغيل لهذه الميزة:**
- "العرض فوق التطبيقات الأخرى" (Draw over other apps) — من إعدادات النظام.
- إذن تسجيل الشاشة (نافذة نظام قياسية تظهر تلقائياً عند الضغط على "تشغيل").

### 3. اللغات
- العربية والإنجليزية فقط، العربية افتراضية.
- التبديل من الإعدادات يعمل فوراً عبر `AppCompatDelegate` (لغة لكل تطبيق، متوافق من Android 8 فما فوق).

### 4. الخطوط
- مدير خطوط يعتمد على **خطوط النظام المضمونة** (Default / Sans Serif / Serif / Condensed) — تدعم العربية عبر نظام Font Fallback المدمج في أندرويد، دون أي اعتماد على إنترنت حتى لأول استخدام.
- شريط تحكم بحجم الخط (85% – 140%) ينعكس فوراً على كل الشاشات.
- **لإضافة خط .ttf خاص بك لاحقاً**: ضعه في `app/src/main/res/font/`، ثم أضف عنصراً جديداً في enum بملف
  `app/src/main/java/com/tarjaman/offline/ui/font/AppFont.kt` (تعليمات مفصّلة داخل الملف نفسه).

### 5. المظهر
- Material 3 كامل + Dynamic Color على Android 12+.
- وضع ليلي/نهاري/اتباع النظام.

### 6. السجل
- آخر 30 ترجمة محفوظة محلياً فقط (بدون أي مزامنة سحابية).

## قرارات هندسية مهمة (ولماذا)
- **ML Kit Translate بدل TFLite/ONNX مخصص**: أخف، أكثر استقراراً، مُختبر على نطاق واسع، ولا يحتاج إدارة Tokenizer يدوياً — الأنسب للأجهزة الضعيفة مثل Redmi.
- **DataStore بدل Room/SharedPreferences**: أخف وأحدث وآمن من تلف البيانات، ويكفي تماماً لحجم البيانات هنا (تفضيلات + سجل 30 عنصراً).
- **DI يدوي بسيط بدل Hilt**: تجنّب تعقيد وحجم بناء إضافي من معالجات annotation processing غير مبرر لحجم هذا المشروع.
- **التقاط شاشة عند الطلب فقط (وليس بثاً مستمراً)**: يقلل استهلاك البطارية والمعالج بشكل كبير جداً على الأجهزة الضعيفة.

## ملاحظة شفافية
تم بناء هذا المشروع في بيئة بدون Android SDK ولا اتصال إنترنت، لذلك **لم يُشغَّل بناء Gradle فعلي لإنتاج APK/AAB هنا**. تمت مراجعة كل ملف يدوياً (توازن الأقواس، صحة XML، الاستيرادات، توافق الإصدارات)، لكن يُنصح بعد أول Sync في Android Studio بمراجعة أي تحذير قد يظهر في نافذة Build خاص بإصدارات مكتبات معينة.

## الحزمة والتوقيع
- `applicationId`: `com.tarjaman.offline` — فريد تماماً، يمكن تثبيته بجانب أي تطبيق آخر بلا تعارض.
- نسخة Debug تُثبَّت بلاحقة `.debug` منفصلة تماماً عن أي نسخة Release مستقبلية بنفس الـ ID الأساسي.
- **قبل النشر الفعلي**: يجب إنشاء Release Keystore خاص بك (`Build > Generate Signed Bundle/APK`) بدل الاعتماد على توقيع Debug.
